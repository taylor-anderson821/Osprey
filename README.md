# Osprey

***What is Osprey?***

Osprey generares soaring analytics for RC sailplanes and gliders by analyzing vario telemetry from Spektrum recievers. Osprey processes telemetry TLM files generated by Spektrum transmitters, and generates two Excel files as outputs.  The first Excel file provides analytics and charts on  thermal flying performance for each flying session, which is typically recorded between throttle cut OFF to throttle cut ON. The other Excel file records a daily history of your thermal flying stats. Osprey has been tuned to analyze thermal performance for e-gliders, but may be adjusted for DLG performance as well.

***Why should I use Osprey?***

Osprey provides insights into how many thermals you are catching, how long you're in them for, and the altitudes where you are entering and exiting them.  Osprey does this by analyzing altitude and vario time series data, and identifying the points at which you peaked in a thermal, peaked after a launch, and reached the bottom of any troughs between those events.
